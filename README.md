# Alzheimer's Disease Classification from Brain MRI

This project uses Deep Learning (Transfer Learning with VGG16) to classify brain MRI scans into four stages of Alzheimer's Disease. It is designed to run in Google Colab and leverages the Kaggle API for data retrieval.

> **⚠️ Medical Disclaimer**: This project is for **educational and research purposes only**. It is not intended for clinical use, medical diagnosis, or treatment. The results generated by this model should not be used as a substitute for professional medical advice from a qualified healthcare provider.

## 📊 Dataset
The dataset used is the [Alzheimer MRI 4 Classes Dataset](https://www.kaggle.com/datasets/marcopinamonti/alzheimer-mri-4-classes-dataset) from Kaggle.

### Classes:
- **Non-Demented**: 3200 images
- **Very Mild Demented**: 2240 images
- **Mild Demented**: 896 images
- **Moderate Demented**: 64 images

## 🏗️ Model Architecture
- **Base Model**: VGG16 (Pre-trained on ImageNet)
- **Fine-tuning**: Transfer Learning with frozen base layers.
- **Top Layers**:
    - Global Average Pooling
    - Dense (512 units, ReLU)
    - Batch Normalization & Dropout (0.5)
    - Dense (256 units, ReLU)
    - Batch Normalization & Dropout (0.3)
    - Output: Softmax (4 classes)

## 📈 Performance
- **Accuracy**: ~58.13% on the Test Set.
- **Optimizer**: Adam (Learning Rate: 0.001)
- **Techniques**: Data Augmentation (Rotation, Flip, Zoom) and Class Weights to handle data imbalance.

## 🚀 How to Use
1. **Kaggle API**: Set up your Kaggle API key in Colab Secrets (`KAGGLE_USERNAME`, `KAGGLE_KEY`).
2. **Run Notebook**: Execute the cells to download data, train the model, and evaluate results.
3. **Inference**: Use the provided `predict_alzheimer` function in `inference_function.py` to test new images.

## 📂 Project Structure
- `Models/`: Contains the best and final trained models (`.h5`).
- `Visualizations/`: Training history plots and confusion matrices.
- `Reports/`: Classification reports and inference scripts.
